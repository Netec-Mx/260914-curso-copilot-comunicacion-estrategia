# Construcción integral de un Kit de Comunicación para Distribuidores con descripciones, copies y argumentos de venta listos para usar

### Duración Estimada
60 minutos

### Descripción de la Actividad
En este laboratorio práctico, asumirás el rol de Gerente de Comunicación y Trade Marketing en Cerámicas del Norte. Con el objetivo de garantizar la consistencia de marca en el lanzamiento de la nueva colección de revestimientos cerámicos de textura piedra natural, utilizarás Microsoft 365 Copilot Chat para desarrollar un Kit de Distribución multicanal integral. Diseñarás mensajes alineados para la red de distribuidores, los puntos de venta y el consumidor final, estructurarás la matriz de activos digitales para Microsoft Excel, generarás la orden gráfica para el material POP de punto de venta en Copilot Designer y redactarás el catálogo de textos y argumentos comerciales para Microsoft Word.

---

## Objetivos del Laboratorio
- Estructurar una estrategia de comunicación alineada en los tres niveles de la cadena comercial (Distribuidor, Punto de Venta y Consumidor Final).
- Desarrollar la matriz de inventario de activos del Kit de Distribución en tabla Markdown compatible con Microsoft Excel.
- Diseñar la instrucción visual precisa para generar la maqueta de afiches y piezas POP publicitarias en Copilot Designer.
- Redactar el Catálogo Integrado de Copies, Descripciones de Producto y Argumentarios Comerciales formateado para Microsoft Word.
- Resolver un reto autónomo de adaptación de mensajes ante un cambio de tendencia de mercado.

---

## Prerrequisitos
- Acceso a Microsoft 365 Copilot Chat (Enterprise / Web) y Copilot Designer.

---

### Fase 1: Matriz de Mensajes Tri-Nivel (Distribuidor, Punto de Venta, Consumidor)

**Herramienta objetivo:** Copilot Chat (Estrategia y Arquitectura de Mensajes)

Desarrolla la propuesta narrativa para la nueva línea de cerámicas con textura piedra natural, adaptando el tono, el enfoque y la llamada a la acción para cada uno de los tres niveles comerciales.

```
Actúa como Director de Comunicación de Marca para el sector de acabados arquitectónicos.

Desarrolla la arquitectura de mensajes para el lanzamiento de la colección "Piedra Viva" (cerámica de alta definición con relieve táctil) de Cerámicas del Norte, segmentada estrictamente en los 3 niveles de la cadena comercial:

1. Nivel Distribuidor (B2B Mayorista): Enfoque en rentabilidad por m², volumen de stock, exclusividad territorial y respaldo logístico. Tono profesional y financiero.
2. Nivel Punto de Venta (Retail / Vendedores de Sala): Enfoque en facilidad de argumentación frente al cliente, exhibición visual atrayente y rotación rápida. Tono dinámico y motivador.
3. Nivel Consumidor Final / Especificador (Arquitectos / Propietarios): Enfoque en estética natural, durabilidad, fácil limpieza y valorización del inmueble. Tono inspirador y aspiracional.
```

---

### Fase 2: Matriz de Inventario del Kit de Distribución para Excel

**Herramienta objetivo:** Copilot Chat para estructuración en Microsoft Excel (Tabla Markdown)

Organiza los recursos del Kit de Comunicación que se entregarán a los distribuidores en una matriz detallada lista para copiar a Microsoft Excel.

```
Con base en la arquitectura de mensajes tri-nivel de la fase anterior, genera una matriz de inventario del Kit de Distribución Digital en formato de tabla Markdown para exportar a Microsoft Excel.

Requisitos de la tabla:
1. Utiliza sintaxis Markdown estándar (| Columna 1 | Columna 2 |).
2. La primera fila debe incluir exactamente estos encabezados:
| ID Activo | Nombre del Recurso | Canal Destino | Formato / Dimensión | Objetivo Comercial | Tipo de Contenido / Copy Incluido |
3. Llena la tabla con 4 filas detallando: Ficha Técnica Comercial (PDF para Distribuidor), Banner para Redes Sociales (1080x1080 para Sala de Venta), Guía de Tono de Voz para Vendedores y Publicación de Lanzamiento para Consumidor Final.
```

---

### Fase 3: Ingeniería de Prompt Visual para Afiche de Punto de Venta en Copilot Designer

**Herramienta objetivo:** Copilot Chat / Copilot Designer (Generación de Imagen)

Diseña la instrucción de texto precisa para obtener la imagen publicitaria del material POP que acompañará la exhibición en los puntos de venta.

```
Actúa como Diseñador Publicitario. Redacta una instrucción de imagen concisa (máximo 3 líneas) lista para ejecutar en Copilot Designer. Debe solicitar un afiche publicitario de alta resolución para punto de venta que muestre un ambiente de baño moderno decorado con cerámicas de textura piedra natural en tonos calidos, iluminación ambiental suave, texto elegante que diga "Siente la Naturaleza" y el logotipo de "Cerámicas del Norte" en la esquina inferior.
```

**Instrucción para el estudiante:**
Copia la instrucción de 3 líneas obtenida, pégala en el chat y ejecútala en Copilot Designer para obtener la pieza gráfica del afiche.

---

### Fase 4: Catálogo de Copies y Argumentario de Venta en Word

**Herramienta objetivo:** Copilot Chat para documentación en Microsoft Word

Sintetiza la narrativa, las descripciones técnicas y los argumentos comerciales en un manual completo formateado para Microsoft Word.

```
Actúa como Copywriter Senior y Redactor Comercial. Con base en la arquitectura tri-nivel y la matriz de activos, redacta el "Manual y Kit de Comunicación de Marca: Colección Piedra Viva" formateado para Microsoft Word.

Estructura el documento en 3 secciones:
1. Catálogo de Descripciones de Producto: 3 versiones de texto descriptivo (Corta de 30 palabras para e-commerce, Mediana de 80 palabras para catálogo impreso y Larga de 150 palabras para sitio web institucional).
2. Kit de Copies para Redes Sociales: 3 textos listos para publicar (LinkedIn para distribuidores, Instagram para arquitectos y WhatsApp Business para vendedores de sala).
3. Guía de Argumentos de Venta Rápida: Tabla de respuesta rápida frente a 3 dudas comunes del cliente (mantenimiento, resistencia al manchado y diferencia frente a la piedra real).
```

---

### Reto Práctico: Adaptación de Kit para Campaña de Remodelación Rápida

**Herramienta objetivo:** Copilot Chat (Resolución Autónoma)

**Escenario de Desafío:**
La dirección comercial decide lanzar una promoción relámpago orientada a la remodelación residencial sin obra compleja ("Instala sobre existente con adhesivo especial"), requiriendo adaptar el kit de comunicación en menos de 24 horas.

**Tu Desafío:**
1. Escribe y ejecuta un primer prompt de máximo 3 líneas para que Copilot genere una tabla Markdown para Excel con 3 nuevos copies ajustados al concepto "Remodelación Rápida".
2. Escribe y ejecuta un segundo prompt breve para redactar una circular interna en texto para enviar a la fuerza de ventas explicando el enfoque del mensaje.

Pistas para construir tus prompts:
- Mantenlos de máximo 3 líneas cada uno.
- Asigna el rol de Especialista en Campañas de Trade Marketing.
- Especifica entregables claros (Tabla Markdown en la parte 1, circular en texto en la parte 2).

---

## Conceptos Clave para Recordar

- Consistencia Tri-Nivel: Mantener la coherencia del concepto visual y conceptual a lo largo de toda la cadena (fábrica-distribuidor-retail-cliente) refuerza la identidad de marca y acelera las ventas.
- Estandarización de Recursos (Kits): Entregar a los distribuidores paquetes de comunicación listos para usar evita que alteren la imagen de la marca con diseños de baja calidad.
- Escalabilidad de Contenidos: Generar múltiples variaciones de extensión (corta, mediana, larga) a partir de una misma idea central optimiza el tiempo de producción del equipo de marketing.

---

## Resultado Esperado del Estudiante

Al finalizar el laboratorio, el estudiante habrá generado en Copilot Chat:
1. El marco estratégico de comunicación tri-nivel (Distribuidor, Punto de Venta y Consumidor).
2. La matriz de inventario de activos del kit de distribución formateada para Microsoft Excel.
3. La instrucción ejecutada para generar el afiche publicitario en Copilot Designer.
4. El Manual y Kit de Comunicación completo formateado para Microsoft Word.
5. Los dos prompts propios resueltos para el reto de adaptación a la campaña de remodelación rápida.
