## Descripción General

En este laboratorio construirás de principio a fin el Kit de Comunicación para Distribuidores de **Marca Nexo — línea de bebidas funcionales**, el entregable central del Módulo 3. Partirás de los outputs estratégicos de los Módulos 1 y 2 (informe de posicionamiento y matriz comercial) para crear un documento profesional en Word con cinco secciones: Arquitectura de Mensajes, Fichas de Producto, Copies por Canal Digital, Argumentario de Ventas y Checklist de Activación por Canal. Utilizarás Copilot en Word de forma intensiva — funciones de Borrador, Reescritura, variación A/B y adaptación de tono — para generar, iterar y refinar cada pieza de contenido, garantizando coherencia de marca y diferenciación por audiencia.

---

## Objetivos de Aprendizaje

Al completar este laboratorio serás capaz de:

- [ ] Diseñar una arquitectura de mensajes rectores diferenciados para distribuidor, punto de venta y consumidor final, manteniendo coherencia con el territorio de marca definido en M1.
- [ ] Construir fichas de producto completas (descripción técnica, beneficios funcionales/emocionales, claims y datos de soporte) utilizando Copilot en Word con referencia contextual a archivos anteriores.
- [ ] Automatizar la adaptación de un concepto comunicacional central a seis formatos distintos (Instagram corto, Instagram largo, LinkedIn B2B, e-mail a distribuidor, ficha e-commerce, headline de catálogo) mediante prompts especializados.
- [ ] Producir un argumentario de ventas profesional con script de presentación, argumentos diferenciados y manejo de objeciones, todo generado y refinado con Copilot.
- [ ] Integrar datos de canales y portafolio del Módulo 2 como contexto para personalizar mensajes por canal de distribución y segmento.

## Instrucciones Paso a Paso

### Paso 1 — Crear el documento base y estructura del Kit (8 minutos)

**Objetivo:** Crear el archivo `M3_Kit_Comunicacion_Distribuidores.docx` con la estructura de cinco secciones que servirá como esqueleto del Kit completo.

**Instrucciones:**

1. Abre **Microsoft Word** y crea un **Documento en blanco**.
2. Guarda inmediatamente el archivo en la ruta de OneDrive:
   ```
   Documentos/CopilotComunicacionEstrategia/M3_Kit_Comunicacion/M3_Kit_Comunicacion_Distribuidores.docx
   ```
3. En la primera línea, escribe el título del documento con formato **Título**:
   ```
   Kit de Comunicación para Distribuidores — Marca Nexo: Bebidas Funcionales
   ```
4. Debajo del título, inserta una línea con la fecha y versión:
   ```
   Versión 1.0 | [Fecha de hoy] | Documento de trabajo — Módulo 3
   ```
5. Crea las siguientes secciones utilizando el estilo **Título 1** para cada una. Deja al menos 3-4 líneas vacías entre cada título para trabajar después:

   ```
   Sección 1: Arquitectura de Mensajes
   Sección 2: Fichas de Producto
   Sección 3: Copies por Canal Digital
   Sección 4: Argumentario de Ventas
   Sección 5: Checklist de Activación por Canal
   ```

6. Guarda el documento (`Ctrl + S`).

**Resultado esperado:** Un documento Word guardado en OneDrive con el título del kit y cinco encabezados de Título 1 que definen la estructura completa.

**Verificación:** Abre el **Panel de navegación** (pestaña **Vista** → marcar **Panel de navegación**). Debes ver los cinco títulos de sección listados jerárquicamente.

### Paso 2 — Arquitectura de Mensajes: Mensaje rector y territorios diferenciados (15 minutos)

**Objetivo:** Utilizar Copilot para generar los mensajes rectores diferenciados por audiencia (distribuidor, punto de venta, consumidor) anclados en el territorio de marca de Marca Nexo, referenciando el archivo M1 como contexto.

**Instrucciones:**

1. Posiciona el cursor debajo del encabezado **Sección 1: Arquitectura de Mensajes**.
2. Haz clic en el icono de **Copilot** en la cinta de opciones o usa el atajo para abrir el **panel lateral de Copilot** en Word.
3. En el panel de Copilot, escribe el siguiente prompt. **Antes de enviarlo**, haz clic en el icono de **Referenciar un archivo** (icono de clip o de documento) y selecciona `M1_Informe_Ejecutivo_Posicionamiento.docx` desde OneDrive:

   ```
   Usando como contexto el archivo de posicionamiento de Marca Nexo referenciado,
   genera una Arquitectura de Mensajes completa con los siguientes elementos:

   1. TERRITORIO DE COMUNICACIÓN: Define el territorio de marca de Marca Nexo
      (bebidas funcionales) en 2-3 oraciones. Debe reflejar el posicionamiento
      estratégico del informe M1.

   2. MENSAJE RECTOR DE MARCA: Una frase de no más de 12 palabras que sintetice
      la promesa central de Marca Nexo para todas las audiencias.

   3. TRES MENSAJES DIFERENCIADOS:
      a) DISTRIBUIDOR (B2B): Enfocado en rentabilidad, rotación proyectada,
         respaldo comercial y programa de sell-out. Incluir al menos un dato
         cuantitativo. Titular (máx. 15 palabras) + 2 oraciones de soporte.
      b) PUNTO DE VENTA (vendedor/tendero): Enfocado en facilidad de venta,
         margen por unidad, material POP disponible y soporte de capacitación.
         Titular (máx. 15 palabras) + 2 oraciones de soporte.
      c) CONSUMIDOR FINAL: Enfocado en beneficio funcional (energía, hidratación,
         rendimiento) y beneficio emocional (bienestar, estilo de vida activo).
         Titular (máx. 15 palabras) + 2 oraciones de soporte.

   4. TABLA DE BENEFICIOS POR AUDIENCIA: Tabla con 3 columnas (Distribuidor,
      Punto de Venta, Consumidor) y 3 filas (Beneficio principal, Tipo de
      beneficio [negocio/ejecución/experiencia], Datos de soporte clave).

   Tono: Profesional, directo, orientado a resultados. Formato: Usa encabezados
   claros y la tabla en formato Markdown.
   ```

4. Revisa la respuesta de Copilot. **Evalúa críticamente** los siguientes aspectos:
   - ¿El territorio de marca es coherente con lo definido en M1?
   - ¿Los datos cuantitativos del mensaje para distribuidor son plausibles?
   - ¿El mensaje del consumidor evita jerga técnica de negocio?
   - ¿La tabla diferencia correctamente los tipos de beneficio?

5. Si necesitas ajustar, usa un prompt de seguimiento en el mismo panel:

   ```
   Ajusta el mensaje del distribuidor para que incluya una referencia explícita
   al crecimiento de la categoría de bebidas funcionales en el último año.
   Mantén el mismo formato y tono del resto.
   ```

6. Una vez satisfecho con el resultado, haz clic en **Insertar** (o **Mantener**) para incorporar el texto al documento.
7. Aplica formato manualmente si es necesario:
   - Subtítulos internos como **Título 2** (Territorio de comunicación, Mensaje rector, etc.).
   - Tabla con formato de tabla de Word (seleccionar texto de tabla → **Insertar** → **Tabla** → **Convertir texto en tabla**, o formatear manualmente).
8. Guarda el documento (`Ctrl + S`).

**Resultado esperado:** La Sección 1 contiene: territorio de marca definido, mensaje rector universal, tres mensajes diferenciados con titular y soporte, y una tabla comparativa de beneficios por audiencia. Todo coherente con el posicionamiento de M1.

**Verificación:**
- Lee los tres titulares en secuencia: deben "sentirse" como la misma marca pero hablar idiomas distintos.
- El titular del distribuidor debe contener al menos un dato numérico o referencia de negocio.
- El titular del consumidor no debe mencionar márgenes, rotación ni términos B2B.

### Paso 3 — Fichas de Producto: Generación de 3 fichas completas (18 minutos)

**Objetivo:** Generar fichas de producto profesionales para tres productos/líneas de Marca Nexo, integrando datos del portafolio definido en M2 y utilizando Copilot para producir descripciones técnicas, beneficios y claims de marketing.

**Instrucciones:**

1. Posiciona el cursor debajo del encabezado **Sección 2: Fichas de Producto**.
2. Primero, necesitas establecer contexto del portafolio. Abre el panel lateral de Copilot y referencia el archivo `M2_Estrategia_Comercial_Precios.xlsx`:

   ```
   Revisa el archivo M2 de estrategia comercial referenciado e identifica los
   3 productos o líneas principales de Marca Nexo (bebidas funcionales) con
   sus precios, canales prioritarios y características clave. Preséntame un
   resumen breve en formato de lista.
   ```

3. Toma nota mental (o copia en un comentario temporal) de los 3 productos identificados. Si Copilot no puede leer datos específicos del Excel, utiliza los siguientes productos del caso guía:

   | Producto | Descripción breve |
   |---|---|
   | **Nexo Energía** | Bebida funcional con cafeína natural, vitaminas B y electrolitos. 350 ml. |
   | **Nexo Hidra+** | Agua funcional con minerales, zinc y vitamina C. Sin azúcar. 500 ml. |
   | **Nexo Focus** | Bebida con L-teanina, ginseng y vitaminas del complejo B. 250 ml. |

4. Ahora genera la primera ficha completa. En el panel de Copilot, escribe:

   ```
   Genera una ficha de producto profesional para "Nexo Energía" (bebida funcional
   con cafeína natural, vitaminas B y electrolitos, 350 ml) de Marca Nexo.

   La ficha debe incluir exactamente estas secciones:

   NOMBRE DEL PRODUCTO: Nexo Energía
   DESCRIPCIÓN TÉCNICA: 3-4 oraciones con ingredientes clave, formato, contenido
   neto y diferenciador técnico.
   BENEFICIOS FUNCIONALES: Lista de 3-4 beneficios tangibles y medibles.
   BENEFICIOS EMOCIONALES: Lista de 2-3 beneficios ligados a estilo de vida
   y autopercepción del consumidor.
   CLAIMS DE MARKETING: 3 frases cortas (máx. 8 palabras cada una) que podrían
   usarse en empaque, POP o publicidad.
   DATOS DE SOPORTE: 2-3 datos o estadísticas que respalden los claims
   (pueden ser tendencias de categoría o estudios de mercado plausibles).
   CANALES PRIORITARIOS: Basado en la estrategia de M2, indicar los 2-3
   canales donde este producto tiene mayor potencial.

   Formato: Usa encabezados claros. Tono profesional pero accesible.
   ```

5. Revisa la ficha generada. Verifica que:
   - La descripción técnica no contradiga las características del producto.
   - Los claims sean concisos y no contengan promesas médicas no sustentables.
   - Los beneficios emocionales no repitan los funcionales con otras palabras.

6. Inserta la ficha en el documento.

7. Repite el proceso para **Nexo Hidra+** y **Nexo Focus**. Para mayor eficiencia, usa este prompt adaptado para generar ambas fichas en una sola interacción:

   ```
   Ahora genera dos fichas de producto adicionales con la misma estructura exacta
   que la ficha de Nexo Energía, para los siguientes productos:

   PRODUCTO 2: "Nexo Hidra+" — Agua funcional con minerales, zinc y vitamina C.
   Sin azúcar. 500 ml. Posicionado como hidratación inteligente para el día a día.

   PRODUCTO 3: "Nexo Focus" — Bebida con L-teanina, ginseng y vitaminas del
   complejo B. 250 ml. Posicionado para concentración y rendimiento mental.

   Mantén el mismo formato, nivel de detalle y tono que la ficha anterior.
   Diferencia claramente los claims y beneficios de cada producto para que no
   se repitan entre fichas.
   ```

8. Inserta ambas fichas en el documento, debajo de la primera.
9. Aplica formato consistente: usa **Título 2** para el nombre de cada producto y **Título 3** para las subsecciones internas de cada ficha.
10. Guarda el documento (`Ctrl + S`).

**Resultado esperado:** Tres fichas de producto completas, cada una con 7 secciones (nombre, descripción técnica, beneficios funcionales, beneficios emocionales, claims, datos de soporte, canales prioritarios). Las fichas son distintas entre sí en claims y beneficios, pero coherentes en formato y tono.

**Verificación:**
- Compara los claims de los tres productos lado a lado: ningún claim debe ser idéntico o casi idéntico entre productos.
- Cada ficha debe mencionar al menos un canal prioritario diferente (reflejo de la estrategia de M2).
- La descripción técnica de cada producto debe incluir el formato/tamaño (350 ml, 500 ml, 250 ml).

### Paso 4 — Copies por Canal Digital: Adaptación multicanal con variaciones A/B (20 minutos)

**Objetivo:** Generar copies adaptados a seis formatos/canales distintos a partir del mensaje rector y las fichas de producto, utilizando Copilot para producir variaciones de tono, extensión y formato. Incluir variaciones A/B para al menos dos canales.

**Instrucciones:**

1. Posiciona el cursor debajo del encabezado **Sección 3: Copies por Canal Digital**.
2. Antes de generar los copies, añade manualmente un subtítulo introductorio con estilo **Título 2**:
   ```
   Producto de referencia para copies: Nexo Energía
   ```
   > **Nota:** Generarás los copies usando Nexo Energía como producto de referencia. Al final del paso, generarás una adaptación rápida para los otros dos productos.

3. Abre el panel de Copilot y escribe el siguiente prompt maestro multicanal:

   ```
   Usando el mensaje rector de marca y la ficha de producto de "Nexo Energía"
   que ya están en este documento, genera copies adaptados para los siguientes
   6 canales/formatos. Para cada uno, indica el canal, las restricciones de
   formato y genera el copy completo:

   1. INSTAGRAM — CAPTION CORTO (máx. 150 caracteres + 3 hashtags):
      Tono: Enérgico, directo, aspiracional. Incluir emoji relevante y CTA.
      Generar VERSIÓN A y VERSIÓN B (variación A/B).

   2. INSTAGRAM — CAPTION LARGO (máx. 500 caracteres + 5 hashtags):
      Tono: Storytelling breve, conectar con momento de consumo.
      Incluir CTA al link en bio.

   3. LINKEDIN — POST B2B PARA DISTRIBUIDOR (máx. 700 caracteres):
      Tono: Profesional, orientado a oportunidad de negocio.
      Incluir dato de crecimiento de categoría y CTA para agendar reunión.
      Generar VERSIÓN A y VERSIÓN B (variación A/B).

   4. E-MAIL DE PRESENTACIÓN A DISTRIBUIDOR:
      Asunto del correo (máx. 60 caracteres) + cuerpo del e-mail (máx. 200
      palabras). Tono: Formal-cercano, orientado a beneficio comercial.
      Incluir: saludo, propuesta de valor en 2 oraciones, 3 bullets de
      beneficios clave, CTA para agendar llamada, firma.

   5. FICHA DE E-COMMERCE (estilo Amazon/Mercado Libre):
      Título de producto (máx. 80 caracteres con palabras clave SEO) +
      5 bullet points de características/beneficios + descripción corta
      (100 palabras).

   6. HEADLINE PARA CATÁLOGO IMPRESO:
      Una frase de impacto (máx. 10 palabras) + subtítulo de soporte
      (máx. 20 palabras). Tono: Premium, aspiracional.

   Formato de salida: Organiza cada canal con un encabezado claro.
   Marca explícitamente las versiones A y B donde se solicitan.
   ```

4. Revisa los copies generados. Aplica los siguientes criterios de evaluación:

   | Canal | Criterio clave de revisión |
   |---|---|
   | Instagram corto | ¿Respeta el límite de 150 caracteres? ¿Las dos versiones son realmente distintas (no solo sinónimos)? |
   | Instagram largo | ¿Cuenta una micro-historia o pinta un momento de consumo? |
   | LinkedIn B2B | ¿Habla de oportunidad de negocio, no de beneficios de consumidor? |
   | E-mail distribuidor | ¿El asunto genera curiosidad sin ser clickbait? ¿Los bullets son de negocio? |
   | Ficha e-commerce | ¿El título contiene palabras clave buscables? ¿Los bullets son escaneables? |
   | Headline catálogo | ¿Funciona visualmente como un titular grande? ¿Es memorable? |

5. Si algún copy necesita ajuste de tono, usa la función **Reescribir con Copilot**:
   - Selecciona el texto del copy que deseas ajustar.
   - Haz clic derecho → **Copilot** → **Reescribir** (o usa el icono de Copilot que aparece al seleccionar texto).
   - En el cuadro de reescritura, especifica el ajuste:
     ```
     Reescribe este copy con un tono más informal y juvenil, manteniendo
     el mensaje central y el CTA.
     ```
   - Revisa las opciones generadas y selecciona la que mejor se ajuste.

6. Inserta todos los copies en el documento.

7. Ahora genera una adaptación rápida para los otros dos productos. Usa este prompt:

   ```
   Toma los copies de Instagram caption corto (Versión A) y ficha de e-commerce
   que generaste para Nexo Energía y adáptalos para:
   - Nexo Hidra+ (hidratación inteligente, sin azúcar, 500 ml)
   - Nexo Focus (concentración y rendimiento mental, 250 ml)

   Mantén la misma estructura y extensión. Cambia los beneficios y claims
   según la ficha de cada producto. Presenta los 4 copies resultantes
   (2 por producto) con encabezados claros.
   ```

8. Inserta las adaptaciones en el documento bajo un subtítulo **Título 2**: `Adaptaciones para Nexo Hidra+ y Nexo Focus`.
9. Guarda el documento (`Ctrl + S`).

**Resultado esperado:** La Sección 3 contiene copies completos para 6 canales/formatos con variaciones A/B en Instagram corto y LinkedIn B2B, más adaptaciones de 2 formatos para los otros dos productos. Total: al menos 12 piezas de copy distintas.

**Verificación:**
- Cuenta las piezas de copy: debes tener mínimo 12 (6 formatos para Nexo Energía, incluyendo versiones A/B en 2 canales = 8, más 4 adaptaciones para los otros productos).
- Lee el copy de LinkedIn y el de Instagram corto en secuencia: deben sonar como si los hubiera escrito una persona diferente (el de LinkedIn es profesional B2B; el de Instagram es enérgico y directo).
- El e-mail tiene estructura completa: asunto, saludo, propuesta, bullets, CTA, firma.

### Paso 5 — Argumentario de Ventas: Script, argumentos y manejo de objeciones (18 minutos)

**Objetivo:** Construir un argumentario de ventas profesional que incluya un script de presentación de 3 minutos, los 5 argumentos principales diferenciados vs. competencia, y el manejo de 5 objeciones frecuentes con respuestas modelo.

**Instrucciones:**

1. Posiciona el cursor debajo del encabezado **Sección 4: Argumentario de Ventas**.
2. Crea tres subtítulos con estilo **Título 2**:
   ```
   4.1 Script de Presentación (3 minutos)
   4.2 Top 5 Argumentos de Venta vs. Competencia
   4.3 Manejo de Objeciones Frecuentes
   ```

3. **Script de presentación.** Posiciona el cursor debajo de `4.1` y abre Copilot. Referencia el documento actual (que ya contiene las secciones 1-3):

   ```
   Usando la arquitectura de mensajes y las fichas de producto que ya están
   en este documento, genera un script de presentación de ventas de exactamente
   3 minutos (aproximadamente 400-450 palabras habladas) para que un vendedor
   de Marca Nexo presente la línea de bebidas funcionales a un distribuidor
   en una reunión presencial.

   Estructura del script:
   - APERTURA (30 seg): Gancho con dato de mercado impactante sobre bebidas
     funcionales + presentación de Marca Nexo en 1 oración.
   - PROPUESTA DE VALOR (60 seg): Por qué Marca Nexo es una oportunidad de
     negocio. Incluir dato de rotación, margen y crecimiento de categoría.
   - PORTAFOLIO (60 seg): Presentar brevemente los 3 productos (Nexo Energía,
     Nexo Hidra+, Nexo Focus) con un beneficio clave de cada uno.
   - SOPORTE COMERCIAL (20 seg): Qué ofrece Marca Nexo al distribuidor
     (material POP, programa de activación, capacitación).
   - CIERRE (10 seg): CTA claro — siguiente paso concreto (agendar piloto,
     enviar propuesta comercial).

   Formato: Indica los tiempos entre corchetes al inicio de cada sección.
   Tono: Conversacional-profesional, como si el vendedor hablara con confianza
   pero sin ser agresivo. Incluir indicaciones entre paréntesis para pausas
   o énfasis (ej: "[pausa breve]", "[mostrar catálogo]").
   ```

4. Revisa el script. Verifica que:
   - El conteo de palabras está entre 380-470 (selecciona el texto → pestaña **Revisar** → **Contar palabras**).
   - Cada sección tiene la proporción de tiempo indicada.
   - No se usan tecnicismos que un distribuidor no entendería.

5. Inserta el script en el documento.

6. **Top 5 argumentos de venta.** Posiciona el cursor debajo de `4.2` y escribe en Copilot:

   ```
   Genera los 5 argumentos de venta más poderosos de Marca Nexo (bebidas
   funcionales) diferenciados frente a la competencia (marcas genéricas de
   bebidas energéticas y aguas saborizadas).

   Para cada argumento incluye:
   - ARGUMENTO (1 oración contundente)
   - EVIDENCIA (dato, tendencia o hecho que lo respalda)
   - FRASE DE CIERRE para el vendedor (cómo decirlo en una conversación)

   Presenta los 5 argumentos en formato de tabla con 3 columnas:
   Argumento | Evidencia | Frase de cierre

   Los argumentos deben cubrir: (1) rentabilidad, (2) tendencia de mercado,
   (3) calidad de ingredientes, (4) soporte comercial, (5) diferenciación
   de portafolio.
   ```

7. Inserta la tabla de argumentos en el documento.

8. **Manejo de objeciones.** Posiciona el cursor debajo de `4.3` y escribe:


## Solución de Problemas

### Problema 1: Copilot no puede referenciar los archivos M1 o M2

**Síntomas:** Al hacer clic en el icono de referenciar archivo en el panel de Copilot, los archivos `M1_Informe_Ejecutivo_Posicionamiento.docx` o `M2_Estrategia_Comercial_Precios.xlsx` no aparecen en la lista, o al seleccionarlos Copilot responde con "No puedo acceder a ese archivo" o genera contenido genérico sin datos específicos de los módulos anteriores.

**Causa:** Los archivos no están sincronizados correctamente en OneDrive, están almacenados localmente fuera de la estructura de OneDrive, o el índice de búsqueda de Microsoft 365 aún no los ha procesado (especialmente si fueron creados o movidos recientemente).

**Solución:**
1. Abre el **Explorador de archivos** y navega a `Documentos/CopilotComunicacionEstrategia/`. Verifica que las carpetas `M1_Informe_Ejecutivo/` y `M2_Estrategia_Comercial/` muestran el icono de nube con check verde (sincronizado).
2. Si muestran un icono de nube sin check, haz clic derecho → **Mantener siempre en este dispositivo** para forzar la sincronización.
3. Abre cada archivo brevemente en su aplicación respectiva (Word para M1, Excel para M2), espera 10 segundos y ciérralos. Esto actualiza el índice.
4. Espera 2-3 minutos y vuelve a intentar la referencia en Copilot.
5. Si el problema persiste, copia manualmente los datos clave del archivo M1 o M2 directamente en el prompt de Copilot como texto plano (ej: "El posicionamiento de Marca Nexo es... Los canales prioritarios son..."). Esto funciona como alternativa inmediata mientras se resuelve la sincronización.

---

### Problema 2: Copilot genera copies que exceden los límites de caracteres especificados

**Síntomas:** Al solicitar un copy de Instagram de máximo 150 caracteres, Copilot genera textos de 200-300 caracteres. Los copies para e-commerce exceden los bullet points solicitados. El script de presentación resulta significativamente más largo o más corto que los 3 minutos requeridos.

**Causa:** Los modelos de lenguaje no cuentan caracteres con precisión; estiman extensión por tokens, lo cual no tiene correlación exacta con caracteres o palabras en español. Además, cuando el prompt contiene mucho contexto, Copilot tiende a generar respuestas más extensas.

**Solución:**
1. **Para copies cortos (Instagram, headlines):** Después de generar el copy, selecciónalo y verifica el conteo manualmente (en Word: seleccionar texto → clic derecho → **Contar palabras** muestra caracteres con y sin espacios).
2. Si excede el límite, selecciona el texto y usa **Reescribir con Copilot** con esta instrucción específica:
   ```
   Acorta este texto a exactamente [X] caracteres o menos, sin perder
   el mensaje central ni el CTA. Cuenta los caracteres incluyendo espacios.
   ```
3. Si Copilot sigue excediendo, edita manualmente: elimina adjetivos redundantes, reemplaza frases por palabras más cortas, o fusiona dos ideas en una.
4. **Para el script de presentación:** Después de generar, haz un conteo de palabras. Un script de 3 minutos hablado a ritmo conversacional equivale a 390-450 palabras en español. Si el resultado está fuera de rango, pide a Copilot:
   ```
   Este script tiene [X] palabras. Necesito exactamente entre 400 y 450
   palabras para una presentación de 3 minutos. [Acorta/Extiende] las
   secciones de [Propuesta de valor/Portafolio] para alcanzar el objetivo.
   ```
