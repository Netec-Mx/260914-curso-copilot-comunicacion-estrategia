# Elaboración del Brief de Innovación en Word y Automatización de la Presentación Ejecutiva del Plan de Lanzamiento en PowerPoint

### Duración Estimada
90 minutos

### Descripción de la Actividad
En este laboratorio práctico, asumirás el rol de Gerente de Innovación y Trade Marketing en Cerámicas del Norte. Con el propósito de estructurar el lanzamiento de una nueva categoría de porcelanatos antideslizantes de alta tecnología para exteriores y zonas húmedas, diseñarás un Agente Personalizado de Copilot que centralice los lineamientos de Trade Marketing. A través de este agente, generarás la documentación técnica para Microsoft Word, la matriz de inversión para Microsoft Excel, la orden gráfica para Copilot Designer y la estructura completa de diapositivas ejecutivas para Microsoft PowerPoint.

---

## Objetivos del Laboratorio
- Configurar y desplegar un Agente Personalizado de Copilot especializado en Trade Marketing e Innovación.
- Generar el Brief de Innovación y Desarrollo de Producto alineado a los estándares de marca para Microsoft Word.
- Construir la matriz de presupuesto y distribución de material POP por zona en tabla Markdown para Microsoft Excel.
- Diseñar la instrucción gráfica y ejecutar el render visual del concepto de exhibición en Copilot Designer.
- Estructurar el guion completo de diapositivas y el plan de comunicación ejecutiva para Microsoft PowerPoint.
- Modificar las reglas del agente en vivo para adaptar sus respuestas a escenarios de sostenibilidad y certificaciones ambientales.

---

## Prerrequisitos
- Acceso a Microsoft 365 Copilot Chat / Copilot Studio o Creador de Agentes Personalizados.

---

### Fase 1: Creación y Configuración del Agente Personalizado de Trade Marketing

**Herramienta objetivo:** Copilot Studio / Configuración de Agentes Personalizados

Aprende a diseñar las instrucciones de sistema (System Prompt) e implementar tu propio agente especializado en Trade Marketing e Innovación Cerámica.

#### 1. Prompt de Sistema para la Creación del Agente:
Copia y ejecuta este prompt en Copilot Chat para obtener la instrucción exacta de tu agente:

```
Actúa como Arquitecto de Agentes de IA. Redacta el Prompt de Sistema (System Instructions) completo e independiente para crear un Agente Personalizado llamado "TradeMarketing-Innovacion-Bot".

El texto redactado debe incluir estrictamente dentro de un bloque de código:
1. Rol: Especialista Senior en Trade Marketing e Innovación para la industria de recubrimientos cerámicos y porcelánicos.
2. Conocimiento Base: Experiencia en exhibición en punto de venta, materiales POP, dinámicas con distribuidores, métricas de sell-in/sell-through y formatos de gran tamaño.
3. Reglas de Comportamiento: Debe entregar siempre respuestas estructuradas por canal, priorizar la viabilidad técnica en salas de venta y mantener un tono comercial-estratégico.
4. Formatos Obligatorios: Tablas Markdown claras para datos numéricos y estructuras listas para pegar en documentos de Microsoft Word y presentaciones de Microsoft PowerPoint.
```

#### 2. Guía Paso a Paso para Desplegar el Agente:
1. **Copiar las Instrucciones:** Copia el texto dentro del bloque de código generado por Copilot (*System Instructions para TradeMarketing-Innovacion-Bot*).
2. **Acceder a la Creación de Agentes:** Abre la plataforma de creación de agentes en Microsoft Copilot (Copilot Studio o el menú *Crear Agente / Custom GPTs*).
3. **Completar Datos Básicos:**
   - **Nombre:** `TradeMarketing-Innovacion-Bot`
   - **Descripción:** *Agente experto en la elaboración de briefs de innovación, estrategias de exhibición en punto de venta y lanzamientos de producto para Cerámicas del Norte.*
4. **Pegar Instrucciones:** Pega el código copiado en el campo **Instrucciones (Instructions / System Prompt)**.
5. **Guardar y Publicar:** Haz clic en **Guardar** o **Publicar**. Abre el panel de pruebas de tu nuevo agente.

### Fase 2: Consumo del Agente — Brief de Innovación de Producto para Word

**Herramienta objetivo:** Agente "TradeMarketing-Innovacion-Bot" / Microsoft Word

Utiliza el agente recién creado para redactar la estructura completa del Brief de Innovación para la nueva línea de porcelanatos antideslizantes.

```
Con base en tu rol de especialista, elabora el "Brief de Innovación y Lanzamiento: Colección AntiSlip Pro 2026" formateado para Microsoft Word.

Estructura el documento en 3 secciones:
1. Oportunidad de Mercado e Innovación Técnica: Justificación de la tecnología antideslizante suave al tacto para porcelanatos de exterior.
2. Perfil del Consumidor Target y Canales Prioritarios: Definición de las necesidades para arquitectos, constructoras y salas de venta retail.
3. Especificaciones de Producto y Presentación: Formatos (60x120 cm y 120x120 cm), paleta de colores y certificaciones de resistencia al deslizamiento (Clase 3 / R11).
```

---

### Fase 3: Consumo del Agente — Matriz de Presupuesto y Material POP para Excel

**Herramienta objetivo:** Agente "TradeMarketing-Innovacion-Bot" / Microsoft Excel

Pide al agente que organice el presupuesto de Trade Marketing e inventario de exhibidores por zona comercial dentro de una tabla Markdown.

```
Genera la matriz de asignación de presupuesto de Trade Marketing y material POP por región en una tabla Markdown lista para exportar a Microsoft Excel.

Requisitos de la tabla:
1. Usa sintaxis Markdown estándar (| Columna 1 | Columna 2 |).
2. Usa exactamente estos encabezados:
| Zona Comercial | Cantidad de Puntos de Venta | Exhibidores Tipo Mueble (Unid) | Paneles Táctiles Muestra | Presupuesto Asignado (USD) | Retorno Esperado (m² Sell-Through) |
3. Llena la tabla con 4 filas (Zona Norte, Zona Centro, Zona Sur y Exportaciones B2B).
```

---

### Fase 4: Consumo del Agente — Generación de Prompt Visual para Copilot Designer

**Herramienta objetivo:** Agente "TradeMarketing-Innovacion-Bot" / Copilot Designer

Utiliza el agente para redactar la instrucción de imagen óptima para visualizar el concepto gráfico de la zona de prueba antideslizante.

```
Redacta una instrucción de imagen concisa (máximo 3 líneas) lista para ejecutar en Copilot Designer. Debe solicitar el diseño 3D fotorrealista de un espacio de demostración interactivo en punto de venta, donde los clientes pueden probar agua sobre la baldosa porcelánica antideslizante, con iluminación focalizada y señalética elegante de "Tecnología AntiSlip Pro".
```

**Instrucción para el estudiante:**
Copia la instrucción de 3 líneas entregada por el agente, pégala en el chat general y ejecútala en Copilot Designer para obtener el render de la zona interactiva.

---

### Fase 5: Consumo del Agente — Presentación Ejecutiva de Lanzamiento para PowerPoint

**Herramienta objetivo:** Agente "TradeMarketing-Innovacion-Bot" / Microsoft PowerPoint

Solicita al agente la estructura y el contenido diapositiva por diapositiva para ensamblar la presentación ejecutiva de lanzamiento.

```
Diseña el guion y contenido completo para la presentación ejecutiva del plan de Trade Marketing en Microsoft PowerPoint.

Estructura la respuesta para 3 diapositivas clave:
- Diapositiva 1 (Estrategia de Innovación): Título, 3 viñetas con la propuesta de valor y nota de sugerencia para incluir el concepto redactado en el Brief de Word.
- Diapositiva 2 (Despliegue de Punto de Venta): Título, 3 viñetas con la estrategia de exhibición y referencia a la ubicación de la imagen renderizada en la Fase 4.
- Diapositiva 3 (Proyección de Ventas y Retorno): Título, resumen de los datos presupuestales de la tabla de Excel y llamado a la acción para la fuerza de ventas.
```

---

### Reto Práctico: Modificación e Integración del Agente con Reglas de Sostenibilidad (Leed / EPD)

**Herramienta objetivo:** Configuración del Agente + Panel de Pruebas

**Escenario de Desafío:**
El comité ejecutivo exige que todos los nuevos lanzamientos de porcelanatos incluyan obligatoriamente el enfoque de Sostenibilidad y Certificación LEED para capturar el mercado de edificaciones ecológicas.

**Tu Desafío:**
1. **Modificar el Agente:** Abre la configuración de tu agente `TradeMarketing-Innovacion-Bot` y agrega la siguiente instrucción en sus reglas del Prompt de Sistema:
   > *"Debes integrar siempre el pilar de Sostenibilidad Verde. En cada brief, presentación o tabla, incluye el impacto de las Certificaciones LEED, el uso de un 40% de material reciclado en la pasta cerámica y la Declaración Ambiental de Producto (EPD)."*
2. **Probar la Modificación:** Envía el siguiente prompt a tu agente modificado para comprobar que aplica la nueva regla:

Prompt del Reto:
Genera un apartado complementario de 2 párrafos para el Brief de Word explicando cómo la Colección AntiSlip Pro aporta puntos a la Certificación LEED de grandes proyectos inmobiliarios.

---

## Conceptos Clave para Recordar

- Especialización de Agentes en Microsoft 365: Crear agentes con System Prompts enfocados en Trade Marketing permite mantener criterios homogéneos de exhibición y marca en toda la empresa.
- Flujo Integrado de Trabajo: Un agente capacitado genera el contenido técnico para Word, las matrices numéricas para Excel, los prompts visuales para Designer y las diapositivas para PowerPoint.
- Mantenimiento y Evolución de Agentes: Ajustar las instrucciones del sistema permite actualizar los criterios comerciales (como sostenibilidad o certificaciones) de forma inmediata para todo el equipo.

1. Diseñar el Prompt de Sistema y configurar el agente "TradeMarketing-Innovacion-Bot".

3. Generar la matriz de presupuesto e inventario POP para Microsoft Excel.
4. Diseñar la instrucción visual y ejecutar el render de la zona interactiva en Copilot Designer.
