# Práctica: Creación de un informe ejecutivo de posicionamiento y análisis de portafolio competitivo utilizando Copilot

### Duración Estimada
60 minutos

### Descripción de la Actividad
En este laboratorio práctico, asumirás el rol de Gerente de Estrategia de Producto en Cerámicas del Norte. Frente al lanzamiento de una nueva línea de porcelanatos de gran formato (120x240 cm), utilizarás Microsoft 365 Copilot Chat para aplicar técnicas avanzadas de ingeniería de prompts (RTF y CADO) para segmentar el mercado por canal (distribuidores, puntos de venta y consumidor final), estructurar una matriz de benchmarking competitivo para Microsoft Excel, redactar el informe ejecutivo de posicionamiento para Microsoft Word y sintetizar la estrategia en un kit de comunicación para Microsoft Outlook y Microsoft PowerPoint.

---

## Objetivos del Laboratorio
- Construir e iterar prompts de alta precisión aplicando la fórmula RTF (Rol, Tarea, Formato) y el marco CADO (Contexto, Acción, Detalle, Output) enfocados en estrategia comercial.
- Desarrollar una matriz comparativa de benchmarking de portafolio y precios en tabla Markdown para Microsoft Excel.
- Redactar un Informe Ejecutivo de Posicionamiento Estratégico formateado para Microsoft Word.
- Crear el plan de comunicación multicanal y el esquema de presentación ejecutiva para Microsoft Outlook y Microsoft PowerPoint.

---

## Prerrequisitos
- Acceso a Microsoft 365 Copilot Chat (Enterprise / Web).

---

### Fase 1: Análisis de Mercado y Segmentación Multicanal (Método CADO)

**Herramienta objetivo:** Copilot Chat (Análisis Estratégico y Segmentación)

Utiliza la fórmula CADO para solicitar a Copilot Chat una segmentación detallada de la oferta de porcelanatos de gran formato en los tres niveles de la cadena comercial.

```
Actúa como un Consultor Senior en Estrategia de Mercado para la industria de acabados de construcción.

Analiza el lanzamiento de la nueva colección de porcelanatos de gran formato (120x240 cm) de Cerámicas del Norte y genera una segmentación estratégica detallada adaptada a 3 canales clave:
1. Distribuidor Mayorista: Enfoque en margen financiero, rotación de inventario y logística de transporte de piezas grandes.
2. Punto de Venta (Salas de Exhibición/Retail): Enfoque en material POP, exhibidores táctiles y capacitación a asesores comerciales.
3. Consumidor Final / Arquitectos: Enfoque en diseño de vanguardia, resistencia, lujo accesible y juntas casi invisibles.

Presenta la respuesta dividida claramente por canal con viñetas analíticas directas.
```

---

### Fase 2: Matriz de Benchmarking Competitivo para Excel

**Herramienta objetivo:** Copilot Chat para estructuración en Microsoft Excel (Tabla Markdown)

Estructura una matriz de benchmarking comparando el producto propio frente a dos competidores líderes del sector cerámico para copiar directamente a Microsoft Excel.

```
Con base en la segmentación de la fase anterior, genera una matriz de benchmarking competitivo en formato de tabla Markdown para exportar a Microsoft Excel.

Requisitos de la tabla:
1. Utiliza bordes claros en sintaxis Markdown (| Columna 1 | Columna 2 |).
2. La primera fila debe incluir exactamente los siguientes encabezados:
| Criterio de Comparación | Cerámicas del Norte (Línea Gran Formato) | Competidor A (Importado Italiano) | Competidor B (Nacional Estándar) | Ventaja Competitiva Clave |
3. Llena la tabla con 4 filas evaluando: Precio promedio por m² (USD), Espesor/Resistencia, Gama de Acabados (Mate/Pulido) y Tiempos de Entrega Logística.
```

---

### Fase 3: Redacción del Informe Ejecutivo de Posicionamiento en Word

**Herramienta objetivo:** Copilot Chat para documentación en Microsoft Word

Sintetiza la segmentación y el benchmarking en un informe estratégico formal redactado para Microsoft Word.

```
Actúa como Gerente de Marketing Comercial. Con base en el análisis multicanal y la tabla de benchmarking, redacta el "Informe Ejecutivo de Posicionamiento: Colección Gran Formato 2026" para Microsoft Word.

Estructura el documento en 3 secciones:
1. Propuesta de Valor Diferenciada: Argumento central para posicionar el producto frente a competidores importados.
2. Estrategia Comerciales por Canal: Pilares de activación para Distribuidores, Puntos de Venta y Consumidores.
3. Recomendaciones de Precios y Márgenes: Sugerencias para mantener la competitividad sin descuidar el margen operativo.
```

---

### Fase 4: Kit de Lanzamiento Comercial para Outlook y PowerPoint

**Herramienta objetivo:** Copilot Chat para Microsoft Outlook y Microsoft PowerPoint

Transforma el informe estratégico en los activos finales de comunicación para distribución masiva y comité de ventas.

```
Con base en el informe de posicionamiento, genera dos entregables de comunicación:

1. Correo Comercial para Microsoft Outlook: Redacta un correo persuasivo dirigido a la Red de Distribuidores Nacionales anunciando el pre-lanzamiento, destacando los márgenes de ganancia y convocando a un evento virtual de exhibición.
2. Presentación para Microsoft PowerPoint: Diseña la estructura de una presentación ejecutiva de 3 diapositivas (Diapositiva 1: Oportunidad de Mercado, Diapositiva 2: Comparativa de Portafolio, Diapositiva 3: Plan de Estímulos para la Red de Ventas). Para cada diapositiva especifica título, 3 puntos clave y el elemento visual recomendado.
```

---

### Reto Práctico: Ajuste Estratégico por Entrada de Competidor Low-Cost

**Herramienta objetivo:** Copilot Chat (Resolución Autónoma)

**Escenario de Desafío:**
Un competidor internacional ha introducido una línea de porcelanatos importados de menor espesor a un precio 20% más bajo que afectará directamente las ventas en los Puntos de Venta de la zona norte.

**Tu Desafío:**
1. Escribe y ejecuta un primer prompt de máximo 3 líneas para que Copilot redacte una matriz de argumentarios de ventas (en tabla Markdown para Excel) que el vendedor de sala puede usar para defender la calidad superior de Cerámicas del Norte.
2. Escribe y ejecuta un segundo prompt breve para redactar un comunicado relámpago de 2 párrafos para Outlook capacitando a los asesores comerciales.

Pistas para construir tus prompts:
- Mantenlos de máximo 3 líneas cada uno.
- Asigna el rol de Especialista en Trade Marketing.
- Delimita los productos esperados (Tabla Markdown para el argumentario en la parte 1, texto de comunicado para Outlook en la parte 2).

---

## Conceptos Clave para Recordar

- Técnica CADO (Contexto, Acción, Detalle, Output): Garantiza que los prompts comerciales contengan el trasfondo de negocio necesario para evitar respuestas genéricas.
- Segmentación B2B vs. B2C: Adaptar el mensaje de un mismo producto según el actor (distribuidor busca margen, el consumidor busca estética) aumenta el impacto de la estrategia.
- Reutilización Directa de Contenidos: Un análisis inicial en Copilot alimenta la matriz de Excel, el informe formal de Word, la presentación de PowerPoint y los correos de Outlook.

Al finalizar el laboratorio, el estudiante habrá generado en Copilot Chat:
1. El análisis de segmentación multicanal detallado por tipo de cliente.
2. La matriz de benchmarking competitivo formateada para Microsoft Excel.
3. El Informe Ejecutivo de Posicionamiento formateado para Microsoft Word.
4. El correo de lanzamiento para Microsoft Outlook y el esquema de presentación para Microsoft PowerPoint.
5. Los dos prompts propios resueltos para el reto de contraataque a la competencia low-cost.
